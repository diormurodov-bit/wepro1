# WEPRO Warehouse — Склад гастробара

Интерфейс складского учёта для менеджера по закупкам гастробара **WEPRO**.

Проект выполнен на чистых веб-стандартах (**HTML5**, **CSS3**, **Vanilla JavaScript**) без использования Node.js, npm, React, Next.js или серверных зависимостей.

---

## 🚀 Как запустить через VS Code Live Server

1. Откройте папку проекта в **Visual Studio Code** (`File` → `Open Folder...`).
3. Убедитесь, что в VS Code установлено расширение **Live Server** (от *Ritwick Dey*).
4. Нажмите правой кнопкой мыши по файлу `index.html` и выберите:
   **«Open with Live Server»** (или нажмите сочетание `Alt + L, Alt + O`).
5. Сайт мгновенно откроется в вашем браузере по адресу `http://127.0.0.1:5500/index.html`.

Либо можно просто дважды кликнуть по `index.html` в проводнике и открыть в любом современном браузере!

## 📁 Структура файлов проекта

- `index.html` — семантическая структура страниц (таблица склада на 8 колонок, разделы Блюда, Категории, Заказы, Клиенты, Поставщики, Отчёты, модальные окна).
- `styles.css` — чистый CSS со стилизацией таблицы, статус-бейджей, адаптивностью под мобильные устройства и шрифтом Plus Jakarta Sans.
- `script.js` — интерактивность: живой поиск, табы фильтрации, сортировка по запасу дней, степперы заказа (`+` / `-`), списание остатка, оформление дозаказа с пересчётом KPI и экспорт в CSV для Excel.
- `logo.png` — оригинальный логотип WEPRO.

---

## 📋 Семантика таблицы (требования ДЗ)

- Собрана на тегах `table`, `thead`, `tbody`, `tr`, `th`, `td` (без вёрстки таблицы на div).
- Ровно 8 колонок: Позиция, Остаток, Хватит на, Расход / мес, Дозаказать, Цена, На складе, Статус.
- 2 группы позиций со строками-заголовками через `colspan="8"`:
  - «Ингредиенты и продукты» (6 позиций)
  - «Полуфабрикаты собственного производства» (4 позиции)
- Числовые колонки выровнены вправо (`text-align: right`) и используют моноширинные табличные разряды (`tabular-nums`).
- Статус-бейджи: `.badge--danger` (Критично), `.badge--warn` (Заканчивается), `.badge--ok` (В норме).
